# Contributing to HRMS App

Thank you for your interest in this project!

This repository is published as a personal portfolio project to showcase design, development, and architectural skills. Because this is a personal evaluation and portfolio project:

- **No External Contributions**: We are not accepting pull requests, code contributions, or bug reports from external contributors at this time.
- **Issues and PRs**: Any opened pull requests or issues will be closed.

If you have questions, feedback, or would like to discuss AJ Developments' capabilities, please contact the author directly.
