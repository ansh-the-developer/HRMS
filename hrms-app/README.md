# HRMS Application

A Human Resource Management System built with React and modern web technologies.

## Project Structure

- `apps/frontend-ui-monorepo`: Main frontend application
- `packages/shared`: Shared utilities and components
- `packages/ui`: Reusable UI components

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

## Features

- Employee Management
- Attendance Tracking
- Leave Management
- Payroll
- Performance Management
- Settings
